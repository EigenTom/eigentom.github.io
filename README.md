# eigentom.github.io

This branch combines the academic homepage and the legacy personal blog in one Jekyll build.

The default root page remains the academic homepage. The blog is built from source under `/blog/` and now uses a style aligned with the academic homepage instead of the old material/Hux theme.

## Branches

- `research`: academic homepage source.
- `master`: legacy Jekyll personal blog source, maintained through 2024.
- `temp_merge`: combined experiment branch.

## Routes

- `/`: academic homepage.
- `/blog/`: personal blog index.
- `/blog/archive/`: blog archive.
- `/blog/about/`: redirects to the academic homepage; About and Research are intentionally merged.
- `/blog/:year/:month/:day/:title/`: blog posts.
- `/projects/`: legacy standalone HTML demos, simulators, and 50P50D examples restored from the old blog.

Navigation between the two parts:

- On the academic homepage, the profile navigation exposes `HOMEPAGE` for `/` and `BLOG` for `/blog/`.
- The blog navigation uses `Search`, `Archive`, and `About`; `About` points back to `/`.

The academic homepage is generated from `index.md`, `_layouts/homepage.html`, `_includes/`, `_data/`, `_sass/`, and the root `assets/` directory.

The blog is generated by the same Jekyll build:

- Blog posts live in `_posts/`.
- Blog list/archive/about pages live under `blog/`.
- Blog layouts live in `_layouts/blog.html` and `_layouts/post.html`.
- Blog styling lives in `assets/css/blog.css` and reuses the same design variables from `assets/css/font.css`.
- Blog interactions live in `assets/js/blog.js`: collapsing top navigation, animated mobile menu, search overlay, previous/next homepage pagination, featured-tag expansion, dynamic post catalog, archive tag filtering, subtle hero parallax, and back-to-top progress.
- Legacy blog images and downloadable files live under `blog/img/` and `blog/files/`.
- Legacy standalone HTML projects live under `projects/` and are copied by Jekyll as static files.
- `blog/sw.js` is a compatibility no-op service worker used to unregister the old blog service worker in browsers that previously visited the legacy site.

## Local Setup

Use Ruby through RVM or another version manager so `ruby`, `gem`, and `bundle` come from the same Ruby installation. This repository has been tested with the local RVM Ruby 3.2.x setup used for the previous Jekyll work.

```bash
cd /Users/tomlu/Documents/GitHub/eigentom.github.io
rvm use 3.2.2
bundle install
```

If `/usr/bin/bundle` is picked up instead of the RVM Bundler, start a fresh shell and run `rvm use 3.2.2` again before installing or serving.

## Run Locally

Start the Jekyll server:

```bash
bundle exec jekyll serve
```

Then open:

- Academic homepage: <http://127.0.0.1:4000/>
- Blog: <http://127.0.0.1:4000/blog/>
- Blog archive: <http://127.0.0.1:4000/blog/archive/>
- Blog about page: <http://127.0.0.1:4000/blog/about/>

If port 4000 is already occupied:

```bash
bundle exec jekyll serve --port 4001
```

## Build

Generate the static site into `_site/`:

```bash
bundle exec jekyll build
```

The build output should include:

```text
_site/index.html
_site/blog/index.html
_site/blog/archive/index.html
_site/blog/about/index.html
_site/blog/YYYY/MM/DD/post-slug/index.html
```

## Editing Guide

Academic homepage content:

- Main page copy: `index.md`
- News: `_data/news.yml`
- Publications: `_data/publications.yml`
- Experiences: `_data/experiences.yml`
- Homepage layout: `_layouts/homepage.html`
- Academic styles: `_sass/minimal-light-no-dark-mode.scss`, `_sass/minimal-light.scss`, `assets/css/*.css`

Blog content:

- Posts: `_posts/*.md`
- Blog index: `blog/index.html`
- Blog archive: `blog/archive/index.html`
- Blog about page: `blog/about/index.html`
- Blog layouts: `_layouts/blog.html`, `_layouts/post.html`
- Blog styles: `assets/css/blog.css`
- Blog interactions: `assets/js/blog.js`
- Blog assets: `blog/img/`, `blog/files/`
- Legacy demos and simulators: `projects/`

## Notes

- Keep the academic homepage at `/`; it is the default public entry point.
- Keep blog routes under `/blog/` to avoid route conflicts.
- The old blog's generated `_site` output is no longer copied into this branch. Posts are compiled directly by this repository's Jekyll build.
- Do not commit local build/dependency caches such as `.sass-cache/` or `vendor/`.
